# AI-Based-Cybersecurity-Network-Threat-Intrusion-Profiler
IBM Internship Project

## About
This project uses Artificial Intelligence and Machine Learning to detect and classify network intrusions.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest
- Joblib
- Matplotlib
- Streamlit

## Dataset
NSL-KDD dataset is used for training and testing the machine learning model.

## Methodology
1. Load the dataset
2. Preprocess the data
3. Encode categorical features
4. Split data into training and testing sets
5. Train Random Forest model
6. Evaluate the model
7. Generate intrusion predictions
8. Display results using Streamlit dashboard
